# Заявки с сайта: Telegram, ВКонтакте и почта

Статический сайт на GitHub Pages не может сам слать письма и сообщения — для этого есть **облачный обработчик** в этой папке (Cloudflare Workers, бесплатный тариф обычно хватает).

Каждый канал включается отдельно и только если заданы его данные. Ошибка одного канала не отменяет остальные: заявка считается доставленной, если дошёл хотя бы один.

## Что получите

- Push в **Telegram** на телефон (бот шлёт сообщение с именем, телефоном, авто, услугами и суммой).
- Сообщение от **сообщества ВКонтакте** администратору в личку или в беседу (если заданы секреты ВК).
- Копия на **почту**: по умолчанию через [FormSubmit](https://formsubmit.co) (аккаунт не нужен), либо через [Resend](https://resend.com), если задан API-ключ.

---

## 1. Telegram-бот (5 минут)

1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя, сохраните **токен**.
2. Напишите своему боту любое сообщение.
3. Узнайте **chat_id**:
   - откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`;
   - в ответе найдите `"chat":{"id":123456789}` — это ваш `chat_id`.
4. Чтобы заявки шли **в группу**: добавьте бота в группу, напишите в группе сообщение, снова посмотрите `getUpdates` (id группы отрицательный).

---

## 2. Почта

Адрес получателя задаётся обычной переменной `LEAD_EMAIL_TO` в `wrangler.toml` (не секрет). Если `RESEND_API_KEY` не задан, воркер отправляет копию через FormSubmit.

При первой заявке FormSubmit обычно присылает письмо со ссылкой подтверждения на этот ящик — её нужно открыть один раз, после этого заявки начнут приходить.

Почта через [Resend](https://resend.com) остаётся как запасной путь (нужны API-ключ, подтверждённый домен и `LEAD_EMAIL_FROM`).

---

## 3. ВКонтакте — сообщение от сообщества

Сообщество само пишет администратору в личные сообщения или в беседу. Ключ хранится только в секретах Cloudflare, в код и в GitHub его не кладут.

Канал **включён**, только если заданы оба секрета: `VK_GROUP_TOKEN` и `VK_PEER_ID`. Нет одного из них — ВК молчит, Telegram и почта работают как раньше. Версия API ВК уже прописана в коде (`5.199`), отдельно её задавать не нужно.

### Включить сообщения сообщества

1. Откройте сообщество → **Управление** → **Сообщения**.
2. Включите **Сообщения сообщества** и сохраните.

### Где взять ключ сообщества (VK_GROUP_TOKEN)

1. **Управление** → **Настройки** → **Работа с API**. Если пункта нет в настройках, откройте **Дополнительно** → **Работа с API**.
2. Нажмите **Создать ключ**.
3. Поставьте галочку **Сообщения** и подтвердите.
4. Скопируйте ключ сразу: ВК показывает его один раз. Это и есть `VK_GROUP_TOKEN`.

Ключ в файл не сохраняйте. Команда ниже спросит значение в терминале и положит его в Cloudflare.

### Как узнать, кому слать (VK_PEER_ID)

**Личное сообщение администратору**

1. Администратор открывает диалог с этим сообществом и пишет туда любое сообщение, например «привет». Пока человек сам не написал сообществу или не разрешил сообщения от него, ВК отклонит отправку (ошибка вроде «Can't send messages for users without permission»).
2. Числовой id:
   - адрес страницы `https://vk.com/id123456789` — peer_id это `123456789`;
   - короткий адрес (`https://vk.com/nickname`) — откройте переписку с этим человеком. В ссылке будет `https://vk.com/im?sel=123456789`. Число после `sel=` и есть peer_id.

**Беседа**

1. Добавьте сообщество в беседу и разрешите ему писать.
2. Откройте беседу в браузере. В ссылке:
   - `sel=c15` — номер беседы `15`, peer_id = `2000000000 + 15` = `2000000015`;
   - или сразу `sel=2000000015` — это уже готовый peer_id.
3. В секрет кладётся полное число, например `2000000015`.

### Команды

Из папки `workers/lead-handler` (после входа в Cloudflare, см. следующий раздел):

```bash
npx wrangler secret put VK_GROUP_TOKEN
npx wrangler secret put VK_PEER_ID
npx wrangler deploy
```

Wrangler попросит вставить значение и нажать Enter. `npx wrangler deploy` публикует воркер, чтобы он увидел новые секреты.

## 4. Деплой обработчика

Нужен бесплатный аккаунт [Cloudflare](https://dash.cloudflare.com) и Node.js на компьютере.

```bash
cd workers/lead-handler
npm install wrangler --save-dev
npx wrangler login
npx wrangler deploy
```

После деплоя в терминале появится URL вида:

`https://ml-detailing-leads.<ваш-аккаунт>.workers.dev`

---

## 5. Секреты (не кладите в GitHub)

В той же папке:

```bash
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put TELEGRAM_CHAT_ID
npx wrangler secret put LEAD_CLIENT_KEY    # придумайте длинную случайную строку

# ВКонтакте — оба секрета, иначе канал выключен (см. раздел 3):
npx wrangler secret put VK_GROUP_TOKEN
npx wrangler secret put VK_PEER_ID

# если нужна почта через Resend (иначе достаточно LEAD_EMAIL_TO в wrangler.toml):
npx wrangler secret put RESEND_API_KEY
npx wrangler secret put LEAD_EMAIL_FROM
npx wrangler deploy
```

`LEAD_CLIENT_KEY` — та же строка, что вы пропишете в `js/config.js` в `leads.clientKey` (защита от случайного спама на endpoint).

---

## 6. Подключить сайт

Из корня репозитория:

```bash
python3 tools/set-lead-endpoint.py \
  --endpoint "https://ml-detailing-leads.<аккаунт>.workers.dev" \
  --client-key "ваш-длинный-ключ"
```

Или вручную в `js/config.js`:

```js
leads: {
  endpoint: "https://ml-detailing-leads....workers.dev",
  clientKey: "ваш-длинный-ключ",
},
```

Затем обычный деплой сайта: `tools/deploy.sh "подключены заявки"`.

---

## 7. Проверка

```bash
curl -sS -X POST "https://ml-detailing-leads....workers.dev" \
  -H "Content-Type: application/json" \
  -H "X-Lead-Key: ваш-длинный-ключ" \
  -d '{"name":"Тест","phone":"+7 (999) 000-00-00","car":"Test","items":[],"total":0,"hasOnRequest":false}'
```

Ожидается `{"ok":true,"telegram":true,"email":true,"vk":true}`, если включены все три канала. У канала без секретов будет `false`. Если ВК ещё не настроен, в ответе будет `"vk":false`, а Telegram и почта при этом приходят.

На сайте: раздел «Цены» → заполнить форму → после отправки текст «Мы получили заявку…».

## Локальная разработка

```bash
cd workers/lead-handler
npm install wrangler --save-dev
# секреты для dev: создайте .dev.vars (файл в .gitignore) по образцу .dev.vars.example
npx wrangler dev
```

В `js/config.js` на время можно указать `http://127.0.0.1:8787` как endpoint. Для проверки ВК локально заполните в `.dev.vars` пустые `VK_GROUP_TOKEN` и `VK_PEER_ID` — настоящие значения, не пример из репозитория.
