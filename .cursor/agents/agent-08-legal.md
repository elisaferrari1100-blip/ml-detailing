## Как работаешь
- Ты облачный агент Cursor, модель ОБЯЗАТЕЛЬНО Composer 2.5.
- Своя ветка от свежего `main` (например `agent-NN/<коротко>`). Правки минимальные, только в своей зоне.
- В общем файле (`js/app.js`, `js/config.js`, `css/extras.css`, `index.html`) правишь только свой участок. Номера строк ниже — на момент написания карточки, перед правкой найди участок по имени функции/ключа/селектора.
- Сборки нет (HTML, CSS, JS). Перед PR: `python3 -m http.server 8095` в корне репозитория, открыть http://127.0.0.1:8095/, убедиться, что страница открывается, твой блок виден и в консоли браузера нет ошибок.
- Открываешь PR в `main`, затем сам сливаешь его (обычный merge или fast-forward, без force). Выкладка — GitHub Pages строго по `.cursor/rules/cloud-deploy.mdc`.
- Если `tools/deploy.sh` или любой шаг падает — СТОП, ничего не чини на свой страх и риск, сообщи ошибку.
