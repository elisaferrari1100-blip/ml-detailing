# ML — сайт детейлинг-студии

Одностраничный сайт студии **ML** в Нижнем Новгороде (ул. Коминтерна, 43А, корп. 2).
Статическая копия: HTML, CSS и JavaScript, без обязательной сборки.

## Как открыть

```bash
cd ml-site
python3 -m http.server 8080
```

Затем откройте http://127.0.0.1:8080/

## Перед публикацией

1. **Домен.** Сейчас везде стоит заглушка `https://example.ru`. Замените её на ваш адрес:

   ```bash
   python3 tools/set-domain.py https://ваш-домен.ru
   ```

   Скрипт обновит `js/config.js` (поле `siteUrl`), `index.html`, страницы в `legal/`, `robots.txt`, `sitemap.xml` и `site.webmanifest`.

2. **Реквизиты.** В подвале и юридических страницах оставлены плейсхолдеры — их нельзя публиковать «как есть»:

   - `[ИП ФИО]`
   - `[ИНН]`
   - `[ОГРН/ОГРНИП]`
   - `[email]`
   - `[телефон]`

   Их можно заполнить в `js/config.js` (блок `legal`) и в HTML-страницах `legal/`. Телефон студии для записи `+7 (999) 120-44-88` уже указан на сайте как контакт, но юридический телефон всё равно нужно подтвердить.

3. **Аналитика и верификация.** В `index.html` закомментированы шаблоны Яндекс.Метрики, Яндекс.Webmaster и Google Search Console — раскомментируйте и подставьте свои коды.

4. **Заявки.** Форма шлёт JSON на облачный обработчик (`workers/lead-handler/`): **Telegram + почта**. Пока в `js/config.js` пустой `leads.endpoint`, на сайте отображается запасной вариант (позвонить / VK). Пошагово: [workers/lead-handler/НАСТРОЙКА.md](workers/lead-handler/НАСТРОЙКА.md), затем `python3 tools/set-lead-endpoint.py`. В заявку входят имя, телефон, авто, выбранные услуги и согласие на обработку ПДн.

## Соцсеть

Ведётся сообщество [VK «ML Detailing»](https://vk.ru/mldetailing). Ссылка стоит в шапке, блоке «Мы ВКонтакте» в контактах, подвале и в разметке `sameAs` (вместе с Яндекс Картами).

## Логотип

Файлы бренда лежат в `brand/`:

- `logo-mark.webp` / `logo-hero.webp` — хромовый знак и логотип для героя (старый золотой знак в `brand/old/`);
- `logo-512.png`, `logo-192.png`, `logo-180.png` — растр для иконок;
- `favicon.svg`, `favicon.ico`;
- `apple-touch-icon.png`;
- `og-1200x630.png` — обложка для соцсетей (логотип на фото из студии).

Копии фавиконов также лежат в корне сайта.

## Юридические документы

Это **шаблоны** под российское право, не готовые документы «под ключ». Страницы в том же оформлении:

- `legal/privacy.html` — политика обработки персональных данных (152-ФЗ);
- `legal/consent.html` — согласие на обработку ПДн (отметка в форме заявки обязательна);
- `legal/terms.html` — пользовательское соглашение;
- `legal/cookies.html` — политика cookie + баннер на главной;
- `legal/offer.html` — правила оказания услуг; явно указано, что цены не являются публичной офертой (ст. 437 ГК РФ).

Перед публикацией заполните реквизиты и при необходимости покажите тексты юристу.

## Как поменять тексты и цены

Содержимое главной страницы — в `js/config.js`: услуги, прайс, отзывы, контакты, SEO-тексты, ссылка VK.
